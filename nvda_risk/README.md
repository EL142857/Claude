# NVDA 外部因子量化预测 + 风控 + 实际对比

选一条细分赛道(英伟达),把能拿到的外部影响全部量化成因子,包括**量化机构的行为**,
用滚动训练的预测集合给出 NVDA 未来 1/5/20 日的预测股价和风险区间,再和真实走势逐日对比。

## 运行

```bash
pip install -r requirements.txt
python run.py                # 下载数据(有缓存)→ 建因子 → 滚动预测 → 对比 → output/report.html
python run.py --no-ablation  # 跳过逐组归因,快约 3 倍
python tests/smoke_test.py   # 用随机合成数据检查流程能跑通(数字没有意义)
```

需要网络能访问 `query1.finance.yahoo.com`、`query2.finance.yahoo.com`、`fc.yahoo.com`、
`guce.yahoo.com`(价格)和 `fred.stlouisfed.org`(宏观)。也可以把 CSV 手动放到
`data/raw/`(格式见 `data.py` 顶部注释),程序会直接读本地文件。

| 组 | 内容 |

| 大盘 / 波动率 | 标普、纳指、罗素;VIX、VIX3M、VVIX、SKEW、期限结构、方差风险溢价 |
| 半导体同业 / 供应链 | SMH、AMD、AVGO;台积电、ASML、美光,以及 NVDA 相对强弱 |
| AI 需求方 | 微软、谷歌、亚马逊、Meta、甲骨文(云厂商资本开支买家) |
| 利率 / 信用 / 流动性 | 10y/2y、实际利率、通胀预期、期限利差;高收益利差、NFCI;美联储净流动性 = 资产负债表 − 逆回购 − TGA |
| 宏观 / 大宗 / 地缘 | 美元指数、长债、原油、铜、黄金;中国(FXI、人民币)、台湾(EWT、台币) |
| 财报日历 | 距下次财报天数、预测窗口内是否有财报 |
| **量化机构行为** | 见下 |

### 量化机构行为怎么量化(`quant_flows.py`)

拿不到基金的真实持仓,就用各类基金公开的交易规则从价格反推它们的仓位和资金流:

- **趋势 CTA**:20/60/120/250 日动量信号 × 15% 波动目标,分别算 NVDA 和纳指的估算仓位及 5 日变化
- **波动率目标基金**:敞口 = 10% / max(20 日, 60 日已实现波动),波动一升就机械减仓
- **风险平价**:股债等风险组合,股债同跌时去杠杆;股债相关性
- **杠杆 ETF 收盘调仓**:2 倍 NVDL 每天收盘必须买入/卖出 L(L−1)·r·AUM
- **动量因子拥挤**:MTUM−USMV 价差、NVDA 对动量因子的 beta、动量因子回撤(去杠杆信号)
- **统计套利**:NVDA 相对 SMH 的残差收益 z 值(套利盘会反向交易)
- **日历性机械流**:期权到期周、四巫日、月末/季末再平衡
- **微观结构**:隔夜 vs 日内收益(机构 vs 散户/消息)、成交量冲击、Amihud 流动性

## 模型与风控(`model.py`)

- **收益模型**:Ridge + LightGBM 平均;每 21 个交易日扩展窗口重训,并剔除与测试期重叠的标签(防泄漏)
- **风险模型**:HAR 波动率回归(日/周/月波动 + VIX),用标准化收益的经验分位数给 80%/95% 区间
- **风控仓位**:半凯利(μ/σ²),VIX 期限结构倒挂时减半,上限 ±1 倍,每单位换手扣 5bp

## 对比现实(`evaluate.py`)

样本外区间默认 2024-01-01 至今,对比:
- 随机游走("未来价=今天价")和历史均值漂移:样本外 R²、价格 MAPE
- 只用技术面的模型:外部因子到底有没有增量价值
- 方向命中率(含二项检验 p 值)、IC 和月度 IC t 值、区间覆盖率
- 风控策略 vs 买入持有:收益、夏普、最大回撤
- 逐组剔除归因:哪组外部因子真正有用

## 验证过的事

- 随机数据上没有虚假优势(命中率约 50%,IC≈0),说明没有未来信息泄漏
- 人为埋入"台积电今天 → NVDA 明天"信号后,模型能找出来(IC 0.16,理论上限约 0.24)
- 区间校准:80%/95% 区间实际覆盖约 80%/94%

## 局限

未纳入真实期权链 Gamma 敞口、13F 持仓、做空余额、新闻情绪(需付费或额外数据源)。
股价预测信噪比极低,IC 0.02–0.05 已属可用。不构成投资建议。

## 合并模型:九只科技股共用一个模型(`run_panel.py`)

```bash
python run_panel.py           # 完整运行(约 5 分钟)
python run_panel.py --reuse   # 复用已保存的滚动预测,只重做分析和报告
```

- 股票池:NVDA、AMD、AVGO、AAPL、MSFT、GOOGL、AMZN、META、TSLA(`config.UNIVERSE`)
- 每行是(日期,股票):大盘/宏观/利率/信用/流动性/地缘/量化基金整体仓位对所有股票相同;
  个股技术面、同业篮子、个股 CTA 仓位、统计套利残差、beta、微观结构、财报日历按股票计算(`panel.py`)
- 一个 LightGBM,目标是 5 日收益 ÷ 该股事前波动,带 stock_id(`panel_model.py`)
- 冲击情景(`config.SCENARIOS`):把一组因子推 1σ,看每只股票的预测反应;
  再用历史回归(Newey-West t 值)核对模型说的差异是否真实存在
- 报告:`output/panel/report.html`

### 分层模型(`run_hier.py`)

```bash
python run_hier.py           # 交叉验证 + 4 种模型滚动对比 + 自助法(约 15 分钟,需先跑 run_panel.py)
python run_hier.py --reuse   # 复用已选参数和预测,只重做自助法
python run_panel.py --reuse  # 把结果并入 output/panel/report.html
```

线性模型 y = 股票截距 + Σ(共同斜率 + 个股偏离)×因子,偏离按 c 收缩;c 和 alpha 只用 2024 年前数据做清洗过的滚动交叉验证选择。
与"统一斜率""各股独立""合并 LightGBM"在同一滚动框架下比较;按季度分块自助法检验个股偏离是否显著。

## 从一周到一分钟(`horizon_intraday.py`)

```bash
python horizon_table.py      # 先跑:日线模型 1–60 日的滚动预测
python horizon_intraday.py   # 日内 1 小时/30/15/5/2/1 分钟 + 合并表 → output/horizon_intraday.html
```

日内模型(`intraday.py`):预测下一根 K 线的收益,特征为 NVDA 自身近几根 K 线、QQQ/SMH/SPY 联动、统计套利残差、日内 VIX、
同时段成交量、振幅、时段(开盘/收盘 30 分钟)、开盘动量 × 收盘窗口、期权到期日、财报反应日,以及日线外部因子模型对当天的预测。
Yahoo 只保留最近一段日内数据(60m 约 2 年、5–30m 约 60 天、1–2m 约 30 天),缓存每次运行追加新 K 线。
30 秒及更短需要逐笔数据,Yahoo 不提供。

### 每个预测期独立选模型(`horizon_tuned.py`)

```bash
python horizon_tuned.py   # 每个预测期在自己的训练期内交叉验证选模型,再独立滚动训练 → output/horizon_tuned.html
```

候选模型(`tuning.py`):Ridge、LightGBM 小/中/大、Ridge+LightGBM 混合(小/中/大),按各预测期训练期内清洗过的滚动交叉验证 IC 选择。
结果与"所有预测期用同一套设置"的版本并列对比,并对 8 个预测期做 Bonferroni 多重检验校正。
